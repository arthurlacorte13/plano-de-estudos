# Plano de Estudos

App para organizar estudos de concurso: edital verticalizado, ciclo de estudos, agenda semanal com arrastar e soltar, recorrências, revisões espaçadas (1, 7 e 30 dias), revisão a cada N aulas, cronômetro e histórico.

## Como usar

Abra o link do site (GitHub Pages). Não precisa de conta nem de instalação.

Na primeira vez, o app já abre com o **edital modelo do TRT-MG 3ª Região (Analista Judiciário – Área Judiciária)**: 11 matérias, 134 aulas e um ciclo de estudos (Direito Civil → Administrativo → Constitucional → Processual Civil). Ajuste à vontade: apague, edite ou adicione matérias no Edital.

**Seus dados ficam salvos no seu próprio navegador.** Ninguém mais vê o que você cadastra, nem o dono deste repositório.

- Use sempre o **mesmo link** e o **mesmo navegador**. Os dados aparecem sozinhos toda vez que você abrir.
- Em outro navegador ou aparelho, os dados não aparecem. Para levar seus dados para lá, use o backup.
- Não use janela anônima: tudo some ao fechar.
- Limpar os dados de navegação do navegador apaga seus estudos.

## Backup

Em **Preferências** (ícone de engrenagem):

- **Exportar backup (.json)** baixa um arquivo com todos os seus dados.
- **Importar backup** carrega esse arquivo em outro navegador ou aparelho, ou recupera seus dados depois de uma limpeza.

O app avisa quando seu último backup tiver mais de 7 dias.

## Atualizações

Quando o app é atualizado neste repositório, quem usa o link recebe a nova versão na próxima vez que abrir, e os dados continuam salvos.
